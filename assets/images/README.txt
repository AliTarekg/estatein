Images exported from the Figma file (WebP, resized for the web), plus the Figma
logo and line artwork (SVG, in patterns/).

They are used two ways:
- as design defaults that templates fall back to (logo, hero building, About
  image, Contact gallery), so the site looks right before anything is uploaded;
- as sample content: on theme activation they are copied into the Media Library
  and attached to the sample properties, testimonials and team members, so
  editors can replace them like any other upload.

Images are demonstration content from the Figma community file
"Real Estate Business Website UI Template – Dark Theme" (Produce UI).
